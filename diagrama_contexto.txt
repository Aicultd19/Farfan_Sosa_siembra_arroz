     │
     │ mapa generado, inventario
     ▼
 ┌──────────────────────────────────────────────────────────┐
 │  PROCESO 2: NIVEL 1 – PUZZLE DE CANALES                  │
 │  - Renderiza grilla 10×6 en Canvas                       │
 │  - Jugador coloca/quita piezas de canal                  │
 │  - BFS calcula flujo de agua en tiempo real              │
 │  - Muestra parcelas regadas en HUD                       │
 │  - Victoria: ≥4/6 parcelas conectadas                    │
 └──────────────────────────────────────────────────────────┘
     │
     │ pts1, tiempo restante
     ▼
 ┌──────────────────────────────────────────────────────────┐
 │  PROCESO 3: NIVEL 2 – SIEMBRA DE BÁLAGOS                 │
 │  - Aparecen bálagos pulsantes en posiciones aleatorias   │
 │  - Jugador hace clic antes de que se agote cada bálago   │
 │  - Dificultad creciente (intervalo entre bálagos baja)   │
 │  - Victoria: 20 bálagos sembrados                        │
 └──────────────────────────────────────────────────────────┘
     │
     │ pts2, tiempo total
     ▼
 ┌──────────────────────────────────────────────────────────┐
 │  PROCESO 4: CALCULAR PUNTAJE FINAL                       │
 │  puntaje = pts1 + pts2 + (tiempo_restante × 2)           │
 │  - Muestra tabla de resultados                           │
 │  - Llama al backend vía fetch() POST JSON                │
 └──────────────────────────────────────────────────────────┘
     │
     │ {nombre, puntaje, tiempo, nivel}  JSON / HTTP POST
     ▼
 ┌──────────────────────────────────────────────────────────┐

ENTIDADES EXTERNAS DEL SISTEMA

  Entidad                 Rol
  ─────────────────────   ──────────────────────────────────────
